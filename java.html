Om IN1010 Java Treningsleir (UiO)

IN1010 Java Treningsleir på kode.sask.no hjelper deg å øve til obliger og eksamen i IN1010 – Objektorientert programmering ved Universitetet i Oslo (UiO). Løs oppgaver i Java direkte i nettleseren, sjekk løsningen med AI, simuler terminaloutput, still spørsmål til AI-veilederen og sammenlign med fasit. Trenger du å repetere grunnleggende Python først? Gå til IN1000 (Python).

Temaer og pensum i IN1010

  • Klasser, konstruktører og innkapsling i Java
  • ArrayList, HashMap og generiske beholdere (Generics)
  • Arv, abstrakte klasser, interface og polymorfisme
  • Iterator, Iterable og egne datastrukturer
  • Lenkelister og rekursjon (inkl. eksamensoppgaver som Jernbane og Tog-Validere)
  • Tråder (concurrency), Monitor og Game of Life (Celle)

Ofte stilte spørsmål om IN1010 og IN1000

Dekker oppgavene eksamensnivå i IN1010 ved UiO?

Ja. Oppgavene i IN1010 Java Treningsleir dekker alt fra grunnleggende klasser og ArrayList til klassiske IN1010-temaer som arv, interfaces, generics, Iterator/Iterable, tråder med Monitor, Game of Life (Celle) og eksamensoppgaver med lenkelister og rekursjon.

Hva er forskjellen på IN1000 og IN1010?

IN1000 er innføringsemnet i Python ved UiO, mens IN1010 bygger videre med objektorientert programmering, datastrukturer, rekursjon og samtidighet i Java. På kode.sask.no kan du øve på både IN1000 (Python) og IN1010 i Java.

Hvordan fungerer AI-veiledningen for Java-kode?

Med knappene Sjekk, Kjør, Forklar og Spør AI kan du få umiddelbar tilbakemelding på Java-koden din, simulert terminaloutput og hjelp fra en AI-veileder tilpasset IN1010-pensum, samt ubegrensede oppgaver i oppgavegeneratoren.
